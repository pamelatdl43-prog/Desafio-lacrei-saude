# Desafio-qa-Lacrei

## Visão Geral
Este repositório contém a solução estruturada para o desafio técnico de QA da Lacrei Saúde, abrangendo automação de testes com Cypress, cenários comportamentais em Gherkin, configuração de pipeline de CI/CD e documentação.

## Estrutura do Projeto
- `cypress/e2e/features/`: Contém os cenários de teste em arquivos `.feature` (BDD/Gherkin).
- `.github/workflows/main.yml`: Arquivo de configuração da pipeline de Integração Contínua (CI/CD).
